从资料到脉络

围绕持续随访的核心能力

六个模块覆盖「归集 — 理解 — 协作 — 沉淀」的完整闭环。

01

报告归集

检验、检查与病理报告统一管理，图片报告经 OCR 识别后仍可人工审查修正。

02

智能识别

OCR 自动提取检验指标并匹配标准库，AI 解读把专业数值翻译成通俗结论与复查提醒。

03

趋势理解

重要指标与多项组合指标对齐同一时间轴，结合参考范围观察连续变化与里程碑。

04

会诊协作

聚合患者资料并承接 AgentTeams 多智能体会诊，全过程状态可跟踪、历史可回溯。

05

资料沉淀

分类知识库沉淀随访计划、检查准备与用药资料，支持搜索、摘要与预览。

06

数据自主

全部数据留在自己的主机，敏感字段加密存储，报告分享支持限时限次访问。

本地掌握数据

三步，在自己的主机上运行

默认提供 CPU Compose 配置；NVIDIA GPU 环境可用独立覆盖文件启用。

01

配置环境

terminal — clone & init 
git clone https://github.com/nickzhang1102/oncopath.git
cd oncopath
cp .env.example .env
02

启动默认 CPU 环境

terminal — compose up 
docker compose up -d --build

NVIDIA GPU 环境以独立 Compose 覆盖文件启用，详见仓库部署文档。

03

安全上线

上线前必须配置真实密钥、限制 CORS、修改管理员初始密码，并完成适用的医疗数据合规评估。
