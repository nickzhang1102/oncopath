从资料到脉络

围绕持续随访的核心能力

01

报告归集

检验、检查和病理报告统一管理；OCR 识别结果可人工审查和修正。

02

趋势理解

将重要指标和多项组合指标放入同一时间轴，结合参考范围查看连续变化。

03

会诊协作

通过 AgentTeams 集成入口聚合患者资料、启动会诊并保留可追溯的历史壳。

04

资料沉淀

用分类知识库整理随访计划、检查准备和用药资料，方便后续查阅。

从自部署开始

01

配置环境

git clone https://github.com/nickzhang1102/oncopath.git
cd oncopath
cp .env.example .env
02

启动默认 CPU 环境

docker compose up -d --build

NVIDIA GPU 环境以独立 Compose 覆盖文件启用，详见仓库部署文档。

03

阅读安全说明

上线前必须配置真实密钥、限制 CORS、修改管理员初始密码，并完成适用的医疗数据合规评估。
