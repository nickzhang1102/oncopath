# 公开截图维护

`docs/screenshots/` 与 `website/screenshots/` 中的公开图片来自同一套固定演示数据。它们用于 README 和项目网站，不能替换为本地、测试库或生产环境中的患者资料。

## 生成方式

先启动前端开发服务：

```powershell
cd front
npm run dev -- --host 127.0.0.1 --port 3000
```

在另一终端运行采集脚本：

```powershell
cd front
node scripts/capture-public-screenshots.mjs
```

脚本通过 Playwright 打开真实 Vue 页面，并在 `/api/v1/*` 网络边界返回固定的虚构响应。采集完成后，同名图片会同时写入 `docs/screenshots/` 和 `website/screenshots/`。

## 隐私边界

- 只使用脚本内定义的演示患者、报告与会诊数据；不得接入本地数据库、导出文件或生产 API。
- 姓名使用 `演示患者 A***` 这类掩码形式；电话、证件号和可能标识个人的字段必须遮蔽。
- 每张图片右下角必须保留 `演示数据 · 已脱敏` 水印。
- 脚本会检查常见真实字段字符串；生成后仍须抽查图片，确认不存在真实患者信息、token、内部 URL 或账号。
- README 与 website 使用相同文件名。变更图片后应校验两个目录中同名文件的哈希一致，避免文档与官网出现不同版本。

## 覆盖清单

桌面端覆盖首页指标列表和图表、检验/检查/病理报告、组合指标表格和趋势、虚拟会诊历史与工作台、知识库。移动端覆盖首页、检验报告、组合指标趋势、虚拟会诊和知识库。
